Laboratorio VR de Dados

Como navegar

Uma experiencia de dados em 3D - use no desktop com o mouse ou em VR.

  • Desktop: arraste com o mouse para olhar, use W A S D para caminhar e clique para escolher.
  • Caminhe: cada etapa e um LUGAR na sala - siga a trilha no piso. No Corredor do Tempo, andar para os lados percorre os anos.
  • VR: toque em Enter VR, mire com o olhar (reticulo) e segure para selecionar. Ande de verdade para navegar no tempo.

Voce pode rever isto no botao "?" no canto.
